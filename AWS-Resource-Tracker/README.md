# AWS Resource Tracker  

## Overview  
This Bash script automates cloud resource tracking for AWS by listing:  
- S3 Buckets  
- EC2 Instances  
- Lambda Functions  
- IAM Users  

## Prerequisites  
- **AWS CLI** installed and configured with appropriate permissions.  
- **Bash** shell environment.  

## How to Use  
1. Clone this repository.  
2. Navigate to the `AWS-Resource-Tracker` folder.  
3. Run the script:  
   ```bash
   chmod +x aws_resource_tracker.sh  
   ./aws_resource_tracker.sh
